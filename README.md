# secnet-parttime

i wanted security experience during the school year, not just in the summer. the big internship lists only track summer roles, and part-time security work gets buried under thousands of full-time postings and part-time security guard jobs. so this repo scans the same 5,000 company career boards as [secnet-internships](https://github.com/ihrtkaii/test-1), plus remote job boards and USAJOBS, and keeps the roles a full-time student can actually take.

a role makes the main list when it is entry-level security work, it can be done from Florida (remote) or in the Orlando area, and the schedule fits. "fits" comes in two levels. **confirmed** means the posting states weekly hours that are all 20 or under. **possible** means it says part-time but gives no hours, or gives a range that goes past 20. roles that only say "fall", "spring", "year-round" or "flexible" with no hours go to a separate **worth checking** queue on the dashboard instead of being thrown out.

the list updates every 6 hours. the [dashboard](https://ihrtkaii.github.io/test-2/) has both queues, search and filters, and a "why it's here" note on each role quoting the sentence that decided it. flags tell you what to check before applying, for example `Clearance`, `2+ yrs exp`, `Full-time in summer` or `Location unverified`.

how it works, what it skips, and how to run it are in [DEEP_DIVE.md](DEEP_DIVE.md).
