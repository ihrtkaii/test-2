# secnet-parttime

i wanted security experience during the school year, not just in the summer. the big internship lists only track summer roles, and part-time security work gets buried under thousands of full-time postings and part-time security guard jobs. so this repo scans the same 5,000 company career boards as [secnet-internships](https://github.com/ihrtkaii/secnet-internships), plus remote job boards and USAJOBS, and keeps only the roles a full-time student can actually take.

a role makes the list when it is a security role (not physical security, not senior), it is part-time, a fall/spring/year-round internship, federal student work, or hourly freelance work, any stated hours start at 20 a week or less, and it is remote in the US or in the Orlando area.

the list updates every 6 hours. the [dashboard](https://ihrtkaii.github.io/secnet-parttime/) has search and filters. flags tell you what to check before applying: `Clearance` means the posting asks for an active clearance, `2+ yrs exp` is the experience it asks for, and `Hours may exceed 20` means the stated range goes past 20.

how it works, what it skips, and how to run it are in [DEEP_DIVE.md](DEEP_DIVE.md).
